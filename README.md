# SaiNetra Open Source Trading Tools

Open-source trading automation and risk-management tools created by Dr. Ravindranath G.

This repository contains educational TradingView Pine Script indicators, MT5 Python bot templates, webhook automation examples, and risk-management logic for retail traders.

## Current Repository Contents

- TradingView Pine Script v6 indicators
- NIFTY and BANKNIFTY intraday options/futures study models
- HTF continuation logic
- V-shaped reversal entry logic
- NSE intraday session filters
- Sideways/chop filters
- Protection marker and trend-exit logic
- AlgoTest-style CE/PE and futures alert mapping
- Risk-management disclaimer for responsible use

## Purpose

The purpose of this repository is to help retail traders and automation learners study rule-based trading systems, capital protection, intraday risk control, alert automation, and safer webhook-based execution workflows.

## Technology Used

- TradingView Pine Script v6
- MT5 Python automation concepts
- Webhook-based execution workflows
- Telegram alert concepts
- AlgoTest-style alert mapping

## Important Disclaimer

This repository is for educational, research, and learning purposes only. It is not financial advice, trading advice, or investment advice.
